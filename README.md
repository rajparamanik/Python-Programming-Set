# 🐍 Python Practice Exercises & Code Sets

A curated repository of **Python programming exercises, code sets, and mini-projects** built to practice, refine, and master Python fundamentals, algorithms, and logic.

---

## 📂 Repository Structure 

The repository is organized by topic and difficulty level:

* **01_Basics/** – Variables, data types, string manipulation, and operators.
* **02_Control_Flow/** – Conditionals (`if-elif-else`), `for` loops, and `while` loops.
* **03_Data_Structures/** – Practice sets for Lists, Tuples, Dictionaries, and Sets.
* **04_Functions_Modules/** – Custom functions, scope, lambda expressions, and built-in modules.
* **05_Error_Handling/** – `try-except-else-finally` blocks and raising custom exceptions.
* **06_OOP/** – Object-Oriented Programming (Classes, inheritance, and polymorphism).
* **07_Algorithms/** – Basic sorting, searching, and logic challenges.

## 🚀 Getting Started

### Prerequisites
Make sure you have **Python 3.10 or higher** installed on your machine. You can check your version by running:
```bash
python --version
```

### Running the Code Locally

1. **Clone this repository:**
   ```bash
   git clone https://github.com
   cd your-repo-name
   ```

2. **Navigate to a specific topic directory:**
   ```bash
   cd 02_Control_Flow
   ```

3. **Run a practice script:**
   ```bash
   python exercise_1.py
   ```
